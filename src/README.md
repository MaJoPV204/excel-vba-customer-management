
# VBA Source Code

This directory contains the VBA source code used in the Ditsö Arts & Craft Customer Management System.

## Procedures

- Guardar: Customer registration.
- Buscar: Customer information retrieval.
- Limpiar: Form reset.
- Eliminar: Customer record deletion.
- InstalarBotones: Automated button creation and macro assignment.

The source code is written in Spanish to preserve the original academic learning context.
