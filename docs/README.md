
# Technical Documentation

This directory contains the technical documentation for the Ditsö Arts & Craft Customer Management System.

## Technical Manual

The technical manual includes:

- Project overview.
- System architecture.
- Database structure.
- VBA source code.
- Macro explanations.
- Process flowcharts.
- VBA programming glossary.
- Installation instructions.
- Testing procedures.
- Future improvements.

## Language

The technical manual is written in Spanish to preserve the original academic learning context.

## Purpose

This documentation serves as both a technical reference and evidence of the programming concepts applied throughout the project.
