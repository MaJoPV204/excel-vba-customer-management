## Project Overview

A customer management system developed using Microsoft Excel and Visual Basic for Applications (VBA), designed for Ditsö Arts & Craft, a small business specializing in ceramic plaster figurines, souvenirs, and painting kits.

This project transforms an academic programming exercise into a practical business application, combining process automation, structured data management, and a customized user interface.

## Project Objectives

- Automate customer registration and management.
- Reduce manual data entry errors.
- Prevent duplicate customer identifiers.
- Simplify customer information retrieval.
- Apply VBA programming concepts to a real business scenario.

## Key Features

| Feature | Description |
|---|---|
| Save | Register new customers |
| Search | Retrieve customer information by unique ID |
| Clear | Reset the registration form |
| Delete | Remove existing customer records |
| Validation | Detect empty and duplicate customer IDs |
| Age calculation | Automatically estimate customer age |
| Custom interface | Ditsö Arts & Craft branding |

## System Architecture

The application consists of two worksheets:

### Ingreso - Customer Registration

A customized interface for entering, searching, clearing, and deleting customer information.

### Base de Datos - Customer Database

A structured worksheet containing the following fields:

| Field | Description |
|---|---|
| Customer ID | Unique customer identifier |
| First Name | Customer's first name |
| Last Name | Customer's last name |
| Date of Birth | Customer's birth date |
| Age | Automatically estimated age |
| Phone | Contact number |
| Email | Email address |
